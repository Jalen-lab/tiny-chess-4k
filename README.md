A self-contained, deterministic 0x88 negamax engine with alpha-beta pruning, iterative deepening, a transposition table, quiescence search, and a fixed node budget. It uses only the Python 3.13 standard library.

## Run it

Run the entry with Python 3.13 and the harness-provided MAKEFUN_ENV_URL: python3.13 main.py.
